# Development Roadmap

SignalTrace is being developed phase by phase. Phase 10 is complete in this repository; later phases remain planned.

| Phase | Objective | Status |
| --- | --- | --- |
| 0 | Foundation, documentation, health contract, and tests | Complete |
| 1 | Collect and safely parse initial Windows Sysmon telemetry | Complete |
| 2 | Normalize events and introduce the SQLite event store | Complete |
| 3 | Build SignalTrace behavioral profiles and feature extraction | Complete |
| 4 | Add explainable signals and Isolation Forest anomaly detection | Complete |
| 5 | Correlate anomalies into incidents, timelines, and process chains | Complete |
| 6 | Add local AI explanations over structured evidence | Complete |
| 7 | Evaluate ONNX/ONNX Runtime and Snapdragon CPU/GPU/NPU execution with benchmarks | Complete |
| 8 | Build the premium dashboard and evaluate realtime updates | Complete |
| 9 | Test false-positive behavior and benchmark representative workloads | Complete |
| 10 | Package and deploy for supported Windows environments | Complete |
| 11 | Prepare competition demo and technical documentation | Planned |

Future work must not imply that a planned capability already exists. Controlled simulations, when needed for testing, will be safe and non-malicious.
